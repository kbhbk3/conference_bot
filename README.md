# Бот конференций по международным отношениям

Telegram-бот, который раз в неделю присылает подборку научных конференций по международным отношениям: где и когда проходит, до какого числа принимают заявки, бесплатно ли участие, индексируется ли в РИНЦ, и предупреждает о сомнительных «сборниках за оргвзнос».

## Зачем, если есть каталоги

Каталоги и Telegram-каналы с конференциями публикуют всё подряд: сотни анонсов в неделю по всем наукам. Отдельной рубрики «Международные отношения» там нет, а слово «международная» стоит в названии почти каждой конференции, так что поиск по нему бесполезен. Бот читает поток за вас и оставляет только то, что действительно про МО, а при желании — про вашу узкую тему.

## Как работает

1. Каждые 4 часа бот забирает RSS-ленту [konferencii.ru](https://konferencii.ru) и складывает новые анонсы в базу.
2. Фильтр по ключевым словам (внешняя политика, дипломатия, геополитика, регионоведение, БРИКС, ШОС и т.д.) отсеивает лишнее. Слово «Международная» в статусе конференции фильтр не обманывает.
3. Для оставшихся бот открывает страницу конференции и отдаёт текст нейросети. Она ставит оценку 0–10, насколько это про МО и вашу тему, и вытаскивает формат, оргвзнос, индексацию и тревожные признаки.
4. По понедельникам в 10:00 по Москве приходит сводка. Уже присланное повторно не приходит, конференции с прошедшим сроком заявок отбрасываются.

Без ключа нейросети бот тоже работает, но только на шаге 2.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | подписаться на сводку |
| `/digest` | сводка прямо сейчас |
| `/topic российско-китайские отношения` | уточнить тему |
| `/topic` / `/topic -` | показать / сбросить тему |
| `/status` | сколько анонсов собрано, когда следующая сводка |
| `/stop` | отписаться |

## Запуск

**1. Создайте бота.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и адрес. Он пришлёт токен вида `123456:ABC...`.

**2. Установите зависимости** (нужен Python 3.10+):

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**3. Настройте.** Скопируйте `.env.example` в `.env`, вставьте токен. Для нейросети впишите ключ любого OpenAI-совместимого API (например, DeepSeek). После первого `/start` бот можно закрыть для чужих: впишите свой chat id в `ALLOWED_CHAT_IDS`.

**4. Проверьте без Telegram:**

```bash
python bot.py --demo tests/sample_rss.xml --today 2026-10-02
python tests/test_bot.py
```

**5. Запустите:** `python bot.py`, напишите боту `/start`, затем `/digest`.

## Чтобы бот работал круглосуточно

Пока бот запущен на ноутбуке, он молчит, когда ноутбук выключен. Нужен сервер: подойдёт самый дешёвый VPS с Linux. Скопируйте туда папку, повторите шаги 2–3 и создайте службу, чтобы бот перезапускался сам:

```ini
# /etc/systemd/system/confbot.service
[Unit]
Description=IR conference bot
After=network-online.target

[Service]
WorkingDirectory=/home/user/conf_bot
ExecStart=/home/user/conf_bot/.venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now confbot
journalctl -u confbot -f      # посмотреть журнал
```

Проверка: выключите свой компьютер и напишите боту с телефона.

## Вежливость к источнику

Бот берёт данные из открытой RSS-ленты, которую сайт сам предлагает для подписки, и открывает только страницы отобранных конференций, разрешённые в robots.txt, с паузой 10 секунд между запросами, как просит сайт.

## Файлы

- `bot.py` — команды и расписание
- `sources.py` — загрузка ленты и страниц
- `analyzer.py` — ключевые слова и нейросеть
- `digest.py` — сборка сводки
- `storage.py` — база SQLite
- `tests/` — образец ленты и проверки
